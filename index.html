GitHub アドレス変換

入力変換結果使い方

1. リポジトリ一覧を貼り付け

1行に1件ずつ、例：atx0543/my-html
GitHubの一覧をまとめて貼り付けても大丈夫です。

2. クリックできるアドレス

3. 2種類のアドレスの違い

GitHubの保存場所（リポジトリ）

https://github.com/atx0543/my-html

コードやファイルの一覧を開く住所です。通常はこちらを使います。

公開ホームページ（GitHub Pages）

https://atx0543.github.io/my-html/

HTMLページを表示する住所です。GitHub Pagesの設定が必要です。

注意：ここで作成した「公開ホームページ」の住所は候補です。実際に表示できるかは、各リポジトリでGitHub Pagesを有効にしているか、公開設定や公開フォルダーによって異なります。HTMLファイルが index.html 以外の場合は、ファイル名を末尾に追加することがあります。

特別なリポジトリ名「atx0543.github.io」の公開ホームページ候補は https://atx0543.github.io/ です。
